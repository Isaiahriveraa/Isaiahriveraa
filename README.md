### Currently building — Koda

> **A voice-first AI coding agent for mobile.** You talk to it, and it talks back — reporting *live, out loud,* what it's doing as it works, instead of leaving you to watch a feed of tokens scroll by. Real-time voice-to-voice (Flutter + LiveKit) over a Rust agent runtime. The bet: voice-first agents haven't been built right yet — so we're building it right.
